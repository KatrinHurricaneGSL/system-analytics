AVPM : PUT /api/boards/{id}/columns/reorder

Created by Перейти on нояб. 15, 2026

Изменяет порядок колонок доски.

Доступ: JWT. Дополнительные разрешения не требуются.

Используется в UC-3. Настройка колонок.

Схема работы

Алгоритм

  1. Проверить JWT и получить колонки доски по идентификатору id.

  2. Для каждой колонки найти позицию ее идентификатора в переданном массиве и присвоить полю Order найденный индекс.

  3. Сохранить изменения и вернуть 204 без тела ответа.

Входные параметры

Параметр пути (PATH) и тело запроса (BODY, JSON).

Где

Поле

Тип

Обязательно

Описание

PATH

id

integer

Да

Идентификатор доски

BODY

Массив идентификаторов

integer[]

Да

Идентификаторы колонок в новом порядке

Список должен содержать идентификаторы всех колонок доски.

Ответ

204 No Content: порядок колонок сохранен, тело ответа отсутствует.

Особенности

  • Если идентификатор колонки отсутствует в массиве, ее поле Order получает значение -1.

  • Если идентификатор повторяется, используется индекс его первого вхождения.

  • Идентификаторы колонок других досок не изменяют их порядок.

  • Если доска не найдена, метод может вернуть 204, поскольку список ее колонок пуст.

  • Порядок задач внутри колонок не изменяется.

Пример запроса

PUT /api/boards/101/columns/reorder
Content-Type: application/json

[
  11,
  13,
  12
]

При успешном выполнении сервер возвращает 204 No Content без JSON.
