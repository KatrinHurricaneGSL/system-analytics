AVPM : POST /api/project-charters/{id}/comments

Created by Перейти, last modified on нояб. 14, 2026

Добавляет комментарий к обсуждению устава.

Доступ: право project_charter:access.

Используется в UC-8. Добавление комментария.

Схема работы

Алгоритм

  1. Проверить, что текст комментария не пустой и не состоит только из пробелов. Удалить пробелы в начале и конце текста.

  2. Найти устав по идентификатору.

  3. Сохранить текст комментария, автора из JWT и время создания. Добавить в журнал событие comment_added.

  4. Вернуть созданный комментарий.

Входные параметры

Где

Поле

Тип

Обязательно

Описание

PATH

id

integer

Да

Идентификатор устава

BODY

text

string

Да

Непустой текст

Ответ

200 OK: возвращает объект созданного комментария, а не массив. При повторной отправке запроса создается новый комментарий.

Код

Причина

400

Пустой текст; {"message":"Comment text is required"}

404

Нет устава

Максимальная длина текста комментария составляет 4000 символов, а его копии в журнале 2000 символов. Сервис не проверяет длину текста, поэтому превышение ограничений может привести к ошибке при сохранении. Также действуют общие ограничения доступа.

Пример

Запрос:

{"text":"Уточнить план испытаний"}

Ответ:

{
  "id":901,
  "charterId":101,
  "text":"Уточнить план испытаний",
  "createdByUserId":10,
  "createdByUserName":"Пользователь примера",
  "createdAtUtc":"2026-11-09T09:00:00Z"
}
