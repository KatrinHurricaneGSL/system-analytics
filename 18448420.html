AVPM : POST /api/boards/{boardId}/columns

Created by Перейти, last modified on нояб. 15, 2026

Добавляет новую колонку в конец доски.

Доступ: JWT.

Используется в UC-3. Настройка колонок.

Схема работы

Алгоритм

  1. Проверить JWT и входные данные. Название колонки обязательно и не должно превышать 50 символов.

  2. Найти доску по boardId.

  3. Если isCompleteColumn=true, снять завершающий признак с существующих завершающих колонок. Их неархивные задачи перевести в открытое состояние (isClosed=false).

  4. Создать колонку с порядковым номером Order, равным количеству существующих колонок. Установить CanCompleteTask=true и DisableCreateButton=false.

  5. Сохранить изменения и вернуть 204 без тела ответа.

Входные параметры

Параметр пути (PATH) и тело запроса (BODY, JSON).

Где

Поле

Тип

Обязательно

Описание и ограничения

PATH

boardId

integer

Да

Идентификатор доски

BODY

name

string

Да

Название колонки, не более 50 символов

BODY

isCompleteColumn

boolean

Нет

Признак завершающей колонки, по умолчанию false

Ответ

204 No Content: колонка успешно создана, тело ответа отсутствует.

Ошибки

Код

Причина

Ответ

400

Некорректные входные данные

Стандартная ошибка валидации

Если доска не найдена, возникает исключение, которое контроллер не преобразует в 404.

Пример запроса

POST /api/boards/101/columns
Content-Type: application/json

{
  "name": "Проверка",
  "isCompleteColumn": false
}

При успешном создании сервер возвращает 204 No Content без JSON.
