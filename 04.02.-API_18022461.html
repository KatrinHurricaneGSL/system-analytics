Общие правила

Все методы требуют авторизации через заголовок Authorization: Bearer {token}.

Для запросов с телом используется Content-Type: application/json.

Поля JSON используют формат camelCase, даты передаются строками даты и времени. Поля ответа со значением null не включаются в JSON.

Примеры запросов содержат условные идентификаторы. Для выполнения запросов необходимо использовать идентификаторы существующих записей.

Создание проекта из устава

Вызов методов прямого создания и создания из шаблона

project:create

Изменение сведений о проекте

project:update

Удаление проекта

project:delete

Параметр organizationId в каталоге используется для фильтрации проектов и не проверяет принадлежность пользователя к организации.

Право project:create само по себе не дает возможности управлять участниками проекта. Для этого необходима роль manager в конкретном проекте.

Роль manager и вычисляемый признак canManageMembers не относятся к глобальным разрешениям пользователя.

Для изменения и удаления проекта сервер проверяет права project:update и project:delete. Дополнительная проверка членства в проекте отсутствует.
