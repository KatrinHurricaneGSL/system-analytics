AVPM : GET /api/project-charters/users

Created by Перейти on нояб. 14, 2026

Возвращает список пользователей для выбора ответственного и согласующих при создании или изменении устава.

Доступ: право project_charter:access.

Используется в UC-2. Создание устава.

Схема работы

Алгоритм

  1. Проверить право доступа и получить список пользователей.

  2. Отсортировать пользователей по имени, затем по username в порядке возрастания.

  3. Вернуть массив пользователей для выбора в форме устава.

Входные параметры

Параметры пути (PATH), параметры запроса (QUERY) и тело запроса отсутствуют.

Ответ

200 OK: возвращает массив пользователей.

Поля каждого элемента массива:

Поле

Тип

Описание

id

integer

Идентификатор пользователя

name

string

Имя пользователя

email

string

Электронная почта

username

string

Логин пользователя

Если пользователи отсутствуют, система возвращает 200 OK с пустым массивом [].

Список не фильтруется по организации или наличию права project_charter:approve. Назначение пользователя согласующим не предоставляет ему это право автоматически.

Ошибки

Код

Причина

401

Пользователь не авторизован

403

У пользователя отсутствует право project_charter:access

Другие ошибки доступа описаны в общей документации API.

Пример запроса

GET /api/project-charters/users
