AVPM : 04.02. Управление проектами

Created by Екатерина Попова, last modified on нояб. 14, 2026

Модуль предназначен для создания проектов из утвержденных уставов, выбора активного проекта, управления составом сотрудников и просмотра досок проекта.

  • Функциональная спецификация содержит пользовательские сценарии и реакции системы.

  • API содержит описание методов, схемы работы, входные параметры и ответы.

  • Модель данных описывает таблицы проектов и участников, а также связи между ними.
