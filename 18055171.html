AVPM : GET /api/projects/{projectId}/members

Created by Екатерина Попова, last modified on нояб. 14, 2026

Возвращает список менеджеров и сотрудников проекта.

Доступ: право project:access и членство в проекте либо право project:create.

Используется в UC-4. Изменение состава сотрудников проекта.

Схема работы

Алгоритм

  1. Проверить право project:access и найти проект по идентификатору. Если проект не найден, вернуть 404.

  2. Проверить членство пользователя в проекте или наличие права project:create. При отсутствии обоих условий вернуть 403.

  3. Получить участников проекта и отсортировать их по роли, затем по имени и username.

  4. Вернуть массив участников проекта. Роль manager для просмотра списка не требуется.

Входные параметры

Параметр пути (PATH). Тело запроса и QUERY-параметры отсутствуют.

Ответ

200 OK: возвращает массив объектов ProjectMemberDto со сведениями об участниках проекта.
