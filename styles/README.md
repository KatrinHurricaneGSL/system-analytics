# Стили локального экспорта

Все HTML-страницы подключают `styles/site.css`. Он загружает:

1. `assets/css/batch.local.css` — собранные стили Confluence для типографики, таблиц, навигации и блоков документации.
2. `assets/css/compiled.css` — скачанные стили веб-приложения Confluence; многие правила применяются только к его служебным классам.
3. `styles/export-layout.css` — отступы и адаптация для самостоятельного HTML-экспорта.

Исходные скачанные `assets/css/batch.css` и `compiled.css` сохранены. В `batch.local.css` изменены только пути ресурсов: шрифты и изображения находятся в `assets/css/resources`, поэтому оформление работает без обращения к Confluence/CDN. Один недоступный старый адрес `wait.gif` заменён идентичным индикатором из того же набора.

Прежний `site.css` содержал несобранные фрагменты LESS: импорты `imports/global`, переменные и вложенные правила. Каталога `imports/global` в экспорте нет; создавать пустой файл не нужно. Вместо этих фрагментов используются готовые стили `batch.local.css`. Копия прежнего файла сохранена в `.recovery-tools/site.before-css-update.css`.

Оформление кнопки и исходников PlantUML остаётся в `assets/diagram-code.css` и подключается на страницах со схемами.

## Боковое меню

Все 71 HTML-страница содержит боковую навигацию по 70 страницам пространства. Дерево построено из иерархии оглавления `index.html`, ссылки относительные и работают при открытии файлов с диска. Поиск выполняется по заголовкам локально, без сетевых запросов.

`assets/sidebar.css` задаёт оформление и мобильное меню. `assets/sidebar.js` управляет поиском, сворачиванием веток и сохранением их состояния в браузере. Текущая страница выделяется, её родительские разделы раскрываются автоматически. При печати меню скрывается.
