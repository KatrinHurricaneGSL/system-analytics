AVPM : PUT /api/boards/columns/{columnId}

Created by Екатерина Попова, last modified on нояб. 15, 2026

Изменяет название и признак завершающей колонки.

Доступ: JWT. Дополнительные разрешения и права владельца доски не проверяются.

Используется в UC-3. Настройка колонок.

Схема работы

Алгоритм

  1. Проверить JWT и входные данные. Поле newName обязательно и не должно превышать 50 символов.

  2. Найти колонку по columnId.

  3. Если isCompleteColumn=true, снять завершающий признак с других завершающих колонок доски.

  4. Обновить название (newName) и признак isCompleteColumn.

  5. Установить isClosed всех неархивных задач обновляемой колонки равным isCompleteColumn. Изменение выполняется даже при переименовании колонки.

  6. Сохранить изменения и вернуть 204 без тела ответа.

Входные параметры

Параметр пути (PATH) и тело запроса (BODY, JSON).

BODY

boolean

Признак завершающей колонки, по умолчанию false. При изменении названия необходимо передавать актуальное значение

Ответ

Некорректные входные данные

Стандартная ошибка валидации

Если колонка не найдена, возникает исключение, которое контроллер не преобразует в 404.

Пример запроса

PUT /api/boards/columns/5
Content-Type: application/json

{
  "newName": "Завершено",
  "isCompleteColumn": true
}

При успешном обновлении сервер возвращает 204 No Content без JSON.
