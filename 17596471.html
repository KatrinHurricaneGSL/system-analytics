Связи и ограничения

Связь

Поведение при удалении

Организация → проекты

CASCADE

Проект → участники

CASCADE

Пользователь → членство в проектах

RESTRICT

Назначивший пользователь → назначения

SET NULL для assigned_by_user_id

Устав → проект

SET NULL для project_charters.project_id

Проект → доски

RESTRICT

Проект → нормативное соответствие, отчетность и риски

CASCADE

Проект → CRM-лиды, CRM-взаимодействия и почтовые цепочки

SET NULL

Для поля project_charters.project_id установлено ограничение UNIQUE, которое запрещает связывать один проект с несколькими уставами.

Удаление проекта зависит от ограничений внешних ключей. При наличии связанных досок с RESTRICT удаление блокируется. Если удаление прошло успешно, связанные участники удаляются, а ссылка на проект в уставе обнуляется. Сам устав сохраняется.
