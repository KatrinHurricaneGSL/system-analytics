AVPM : GET /api/project-charters/{id}/versions

Created by Екатерина Попова, last modified on нояб. 14, 2026

Возвращает список сохраненных версий устава.

Доступ: право project_charter:access.

Используется в UC-7. Просмотр истории.

Схема работы

Алгоритм

  1. Проверить право доступа и получить список версий устава.

  2. Отсортировать версии по номеру, затем по идентификатору в порядке убывания.

  3. Для каждой версии проверить наличие сохраненных данных.

  4. Вернуть массив версий устава.

Входные параметры

Параметр пути (PATH). Тело запроса и QUERY-параметры отсутствуют.

Поле

Тип

Обязательно

Описание

id

integer

Да

Идентификатор устава

Ответ

200 OK: возвращает массив версий устава.

Поля каждого элемента массива:

Поле

Тип

Описание

id

integer

Идентификатор записи истории версий

version

integer

Номер версии устава

status

string

Статус устава на момент сохранения

comment

string, nullable

Комментарий к версии

hasSnapshot

boolean

Признак наличия сохраненных данных версии

actionByUserId

integer, nullable

Идентификатор пользователя, выполнившего действие

createdAtUtc

date-time

Дата и время создания версии

Если устав не найден или история версий пуста, система возвращает 200 OK с пустым массивом [].

Для получения сохраненных данных выбранной версии используется отдельный метод GET /api/project-charters/{id}/versions/{version}.

Пример запроса

GET /api/project-charters/101/versions
