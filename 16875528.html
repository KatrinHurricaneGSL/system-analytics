AVPM : POST /api/project-charters/{id}/create-project

Created by Перейти, last modified on нояб. 14, 2026

Создает проект на основе утвержденного устава.

Доступ: право project:create.

Используется в UC-9. Создание или открытие проекта.

Операцию выполняет модуль проектов.

Схема работы

Алгоритм

  1. Найти устав по идентификатору. Проверить статус approved, отсутствие связанного проекта (projectId), наличие названия, цели, бизнес-обоснования и организации.

  2. Начать транзакцию в реляционной БД. Создать проект, используя организацию и название устава. В описание проекта перенести цель устава.

  3. Назначить менеджером ответственного устава. Если ответственный не указан, назначить текущего пользователя.

  4. Если выбран шаблон, проверить его существование, публикацию и отсутствие признака архивирования. Создать доску и применить структуру шаблона. Без шаблона доска не создается.

  5. Связать созданный проект с уставом и обновить дату изменения устава. Завершить транзакцию без увеличения версии устава и добавления событий в журнал.

Входные параметры

Параметр пути (PATH). Тело запроса не передается, необходимые сведения система получает из устава.

Объект project формируется до назначения менеджера и повторно не загружается. Поэтому массив members может быть пустым, поле currentUserProjectRole может отсутствовать, а canManageMembers сохранять значение false.

Для получения актуальных сведений об участниках и правах пользователя необходимо обратиться к API проекта.

Повторное создание проекта из одного устава запрещено. Если при создании проекта возникает ошибка внутри транзакции, система отменяет изменения.
