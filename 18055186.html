AVPM : PUT /api/projects/{projectId}/members

Created by Екатерина Попова, last modified on нояб. 14, 2026

Изменяет состав сотрудников проекта, сохраняя действующих менеджеров.

Доступ: право project:access и роль manager в проекте.

Используется в UC-4. Изменение состава сотрудников проекта.

Схема работы

Алгоритм

  1. Проверить право project:access, существование проекта и наличие роли manager у текущего пользователя.

  2. Обработать массив memberUserIds, удалив повторяющиеся и неположительные идентификаторы. Если массив отсутствует, использовать пустой список [].

  3. Проверить существование всех выбранных учетных записей. Если хотя бы один положительный идентификатор не найден, вернуть 404 без изменения состава сотрудников.

  4. Исключить из переданного списка действующих менеджеров проекта. Удалить сотрудников с ролью member, отсутствующих в новом списке, и добавить новых. Для новых участников сохранить дату назначения в UTC и идентификатор пользователя, выполнившего действие. Существующие назначения оставить без изменений.

  5. Сохранить изменения одним вызовом SaveChanges и вернуть полный список участников, включая менеджеров. Поле updatedAtUtc проекта не изменять.

Входные параметры

Параметр пути (PATH) и тело запроса (BODY, JSON).

Пустой массив memberUserIds удаляет всех сотрудников с ролью member, сохраняя менеджеров.

Ответ

200 OK: возвращает массив объектов ProjectMemberDto с обновленным составом участников проекта.
