AVPM : POST /api/tasks

Created by Екатерина Попова on нояб. 15, 2026

Создает задачу в указанной колонке доски.

Доступ: JWT и разрешение kanban:edit_card.

Используется в UC-4. Создание задачи.

Схема работы

Алгоритм

  1. Проверить JWT, разрешение kanban:edit_card и входные данные. Найти колонку по columnId.

  2. Создать задачу с текущим пользователем в качестве автора и текущей датой UTC. Установить isClosed равным признаку isCompleteColumn выбранной колонки. Остальные поля инициализировать значениями по умолчанию.

  3. Если isFunctionalRequirement=true, сохранить связи с нормативными требованиями из regulatoryRequirementIds. В противном случае использовать пустой список требований.

  4. Проверить связанный с доской проект и синхронизировать матрицу нормативных требований.

  5. Записать действие создания задачи.

  6. Повторно загрузить задачу в формате TaskCardDto и вернуть 201 с заголовком Location.

Входные параметры

Тело запроса (BODY, JSON).

Где

Поле

Тип

Обязательно

Описание и ограничения

BODY

columnId

integer

Да

Идентификатор колонки. Отдельная проверка значения > 0 отсутствует

BODY

title

string

Да

Название задачи, не более 100 символов

BODY

description

string

Да

Описание задачи. Интерфейс передает пустую строку, если описание не заполнено

BODY

isFunctionalRequirement

boolean

Нет

Признак функционального требования, по умолчанию false

BODY

regulatoryRequirementIds

integer[]

Нет

Идентификаторы нормативных требований, по умолчанию []. Значение null не поддерживается

Ответ

201 Created: возвращает объект TaskCardDto с данными созданной задачи.

Структура ответа описана в методе GET /api/tasks/{id}.
