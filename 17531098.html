AVPM : 04.03. Функциональная спецификация

Created by Екатерина Попова, last modified on нояб. 15, 2026

Модуль предназначен для управления досками и задачами проекта. Доска состоит из колонок, в которых размещаются задачи. Задачи могут содержать сведения об исполнителях, сроках, трудозатратах, зависимостях, функциональных и нормативных требованиях, а также ссылки на статьи базы знаний.

Основные точки входа:

  • /dashboard: каталог досок активного проекта.

  • /dashboard?boardId={id}: выбранная доска.

  • /tasks/{id}: отдельная страница задачи.

Для работы с этими страницами необходимы авторизация и выбранный активный проект.

Особенности и ограничения

  1. Завершение (isClosed), архивирование (isArchived) и признак функционального требования хранятся отдельно. Единого статуса задачи нет.

  2. Перемещение в завершающую колонку закрывает задачу, в обычную открывает. Метод изменения статуса не перемещает задачу.

  3. Изменение признака завершающей колонки обновляет isClosed ее неархивных задач без проверки зависимостей и нормативных ограничений. Создание задачи в завершающей колонке также не выполняет эти проверки.

  4. Полное сохранение задачи заменяет исполнителей, зависимости и документные связи. Операции не объединены общей транзакцией, поэтому возможно частичное сохранение.

  5. Порядок колонок сохраняется на сервере, порядок задач внутри одной колонки только на frontend.

  6. Метод /priority не применяет переданное значение. Приоритет изменяется через полное сохранение задачи.

Сценарии использования

UC-1. Выбор доски и поиск задач

Предусловия: выбран доступный проект.

Точка входа: /dashboard.

Действие пользователя

Реакция системы

Открывает каталог досок

Вызывает GET /api/projects/{projectId}/boards. Показывает доски проекта или предлагает создать новую.

Выбирает доску

Записывает boardId в URL, проверяет его наличие в каталоге проекта. Загружает доску и аналитику, отображает колонки и неархивные задачи.

Выполняет поиск

Передает filter в формате JSON. Сервер ищет текст в названии и описании задач без учета регистра. Пустые колонки остаются видимыми.

Включает «Мои задачи»

Показывает задачи с belongsToUser=true, где пользователь назначен исполнителем.

Открывает задачу

Вызывает GET /api/tasks/{id} и показывает модальную форму. Кнопка «Открыть» переводит на страницу задачи.

Альтернативные сценарии: пустая доска доступна для настройки. Если boardId не принадлежит каталогу проекта, система показывает ошибку выбора.

Ошибки: при невозможности загрузить данные система показывает сообщение. На странице задачи отдельно обрабатываются загрузка, отсутствие доступа и ошибка запроса.

UC-2. Создание доски

Предусловия: выбран активный проект.

Точка входа: «Создать доску проекта».

Действие пользователя

Реакция системы

Вводит название и подтверждает

Проверяет непустое название до 100 символов. Вызывает POST /api/boards, создает доску и назначает текущего пользователя владельцем и участником.

Получает результат

Создает колонки To Do, In Progress, Done. Последняя отмечается как завершающая. При 201 открывает доску и обновляет каталог.

Выбирает создание из шаблона

При наличии project_templates:manage предлагает опубликованные неархивные шаблоны и настройки. Создает доску, затем вызывает POST /api/project-templates/{id}/apply.

Ошибки: при некорректном названии или отсутствии проекта форма остается открытой. Если применение шаблона завершилось ошибкой, созданная доска не удаляется.

UC-3. Настройка колонок

Предусловия: доска открыта.

Точки входа: создание колонки, ее заголовок и меню.

Действие пользователя

Реакция системы

Создает колонку

Запрашивает название и признак завершающей колонки. Добавляет колонку в конец списка. Если она завершающая, снимает этот признак с предыдущей.

Изменяет колонку

Позволяет изменить название и завершающий признак. Обновляет isClosed неархивных задач в соответствии с изменениями.

Перемещает колонку

Передает полный список ID колонок в новом порядке. Сервер сохраняет индексы от 0.

Удаляет колонку

Запрашивает подтверждение и удаляет колонку вместе с ее задачами.

Ошибки: название обязательно, максимальная длина составляет 50 символов. Удаление непустой колонки разрешено.

Особенность интерфейса: формы создания и изменения закрываются после отправки запроса, не дожидаясь успешного ответа.

UC-4. Создание задачи

Предусловия: право kanban:edit_card, создание разрешено в выбранной колонке.

Действие пользователя

Реакция системы

Нажимает «Создать задачу»

Открывает форму с названием, признаком функционального требования и выбором нормативных требований.

Заполняет форму и сохраняет

Вызывает POST /api/tasks с идентификатором колонки, названием, пустым описанием и выбранными требованиями. В завершающей колонке устанавливает isClosed=true, в остальных false.

Получает 201

Сохраняет нормативные связи и событие создания. Обновляет доску и открывает задачу для дальнейшего заполнения.

Ошибки: пустое или слишком длинное название вызывает ошибку валидации.

Для сохранения нормативных связей необходим проект, связанный с доской. Если он отсутствует, ошибка может возникнуть после создания самой задачи.

UC-5. Изменение задачи и связей

Предусловия: право kanban:edit_card, карточка задачи открыта.

Действие пользователя

Реакция системы

Изменяет поля задачи

Позволяет редактировать сведения, доступные в настройках карточки доски.

Нажимает «Сохранить»

При изменении колонки сначала вызывает метод перемещения, затем полный PUT /api/tasks/{id}. Обновляет сведения задачи, исполнителей, зависимости, часы и документные связи.

Получает результат

Показывает сообщение об успешном обновлении, перечитывает доску и журнал действий. При ошибке часть изменений может остаться сохраненной.

UC-6. Перемещение задачи

Предусловия: право kanban:move_card, авторство, назначение исполнителем.

Действие пользователя

Реакция системы

Перетаскивает задачу

Вызывает PUT /api/tasks/{id}/move с newColumnId. Проверяет права пользователя.

Перемещает в завершающую колонку

Проверяет необходимые задачи и нормативные ограничения. При успехе меняет колонку, устанавливает isClosed=true и записывает событие.

Перемещает в обычную колонку

Меняет колонку и устанавливает isClosed=false.

Получает результат

При 204 обновляет положение задачи, при отказе показывает сообщение.

UC-7. Завершение и повторное открытие задачи

Предусловия: право kanban:approve_card.

Действие пользователя

Реакция системы

Отмечает задачу выполненной

Вызывает PUT /api/tasks/{id}/status с isClosed=true. Проверяет зависимости и нормативные ограничения.

Получает подтверждение

Закрывает задачу и записывает событие. Колонка не изменяется.

Снимает отметку

Отправляет isClosed=false и открывает задачу без проверок завершения и перемещения.

Завершение блокируется, если:

  • Связанные нормативные требования имеют статус blocked или non_compliant.

  • Не выполнены требования этапа при canCompleteTask=true.

  • Есть незавершенные неархивные необходимые задачи.

Проверки используют сохраненные записи compliance_matrix_links. При нормативном отказе сервер возвращает код нарушения.

Повторная установка текущего значения isClosed возвращает 400.

UC-8. Архивирование и восстановление задачи

Предусловия: право kanban:archive_card. В текущем интерфейсе меню карточки дополнительно зависит от kanban:delete_card.

Действие пользователя

Реакция системы

Архивирует задачу

Вызывает PUT /api/tasks/{id}/archive с true. Задача исчезает с обычной доски, колонка и isClosed сохраняются.

Открывает архив

Загружает архивные задачи с названиями и колонками.

Восстанавливает задачу

Вызывает тот же метод с false. Задача снова появляется на доске.

Альтернативные сценарии: если архив пуст, отображается сообщение об отсутствии задач.

Ошибки: при отказе показывается предупреждение. Несуществующая задача возвращает 400.

UC-9. Удаление задачи

Предусловия: право kanban:delete_card.

Точка входа: меню карточки, действие «Удалить».

Действие пользователя

Реакция системы

Выбирает удаление

Запрашивает подтверждение.

Подтверждает

Вызывает DELETE /api/tasks/{id}. Записывает событие, затем физически удаляет задачу и связанные данные.

Получает результат

При 204 убирает карточку с доски. При ошибке показывает сообщение.

Восстановление удаленной задачи не предусмотрено.
