AVPM : GET /api/project-charters/{id}/approval-journal

Created by Перейти, last modified on нояб. 14, 2026

Возвращает журнал событий создания, изменения, согласования и обсуждения устава.

Доступ: право project_charter:access.

Используется в UC-7. Просмотр истории.

Схема работы

Алгоритм

  1. Проверить право доступа и получить события журнала устава.

  2. Отсортировать события по дате создания, затем по идентификатору в порядке убывания.

  3. Добавить имя инициатора из учетной записи пользователя.

  4. Вернуть массив событий журнала.

Входные параметры

Параметр пути (PATH). Тело запроса и QUERY-параметры отсутствуют.

Ответ

200 OK: возвращает массив событий журнала.

Если устав не найден или журнал не содержит событий, система возвращает 200 OK с пустым массивом [].

После изменения маршрута согласования ссылка approvalStepId из ранее сохраненного события может указывать на удаленный шаг.

Пример запроса

GET /api/project-charters/101/approval-journal
