AVPM : GET /api/tasks/column/{columnId}

Created by Перейти on нояб. 15, 2026

Возвращает список задач колонки, включая архивные, вместе с данными исполнителей.

Доступ: JWT и разрешение kanban:access.

Схема работы

Алгоритм

  1. Проверить JWT и разрешение kanban:access.

  2. Найти все задачи с TaskColumnId, равным переданному columnId.

  3. Загрузить связанных исполнителей (Members). Архивные задачи не исключаются.

  4. Вернуть массив TaskCardModel[] без преобразования в DTO и дополнительной сортировки.

Входные параметры

Параметр пути (PATH). Тело запроса и QUERY-параметры отсутствуют.

Где

Поле

Тип

Обязательно

Описание

PATH

columnId

integer

Да

Идентификатор колонки

Ответ

200 OK: возвращает массив TaskCardModel[]. Если колонка не найдена или не содержит задач, возвращается пустой массив [].
