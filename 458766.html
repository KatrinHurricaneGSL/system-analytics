Описание

Разработка программной системы управления проектной деятельностью авиапредприятия, предназначенной для централизованного планирования, организации и контроля выполнения проектов

Назначение системы

Программная система предназначена для комплексного управления проектной деятельностью авиапредприятия с учетом отраслевых нормативных требований.

Система объединяет процессы инициации проектов, планирования и выполнения задач, управления нормативной документацией, взаимодействия с клиентами, подготовки отчетности и анализа результатов проектной деятельности.

Инициация, планирование и сопровождение проектов

Наблюдатель

Просмотр информации о ходе проектов и отчетности

Функциональные возможности

  • Управление пользователями и правами доступа.

  • Создание и согласование уставов проектов.

  • Создание и управление проектами.

  • Использование шаблонов проектов.

  • Управление канбан-досками и задачами.

  • Ведение нормативных документов и требований.

  • Формирование матрицы соответствия.

  • Подготовка регламентированной отчетности.

  • Управление клиентами и заявками (CRM).

  • Ведение базы знаний.

  • Планирование календарных событий.

  • Почтовые коммуникации.

  • Аналитика проектной деятельности.

Архитектура системы

Система реализуется в рамках клиент-серверной архитектуры и состоит из следующих компонентов:

Компонент

Описание

Frontend

Одностраничное веб-приложение на React и TypeScript

Backend

Модульный монолит на ASP.NET Core

База данных

Реляционная СУБД MySQL

API

REST API для взаимодействия клиентского и серверного приложений

Авторизация

JWT и разграничение доступа на основе ролей и разрешений

Подробная архитектура представлена в разделе https://katerinapopova.atlassian.net/wiki/x/EoALAQ

Ожидаемые результаты внедрения

  • Создание единого информационного пространства для проектной деятельности.

  • Повышение прозрачности выполнения проектов.

  • Упрощение взаимодействия между участниками.

  • Сокращение ручной обработки проектных данных.

  • Упрощение контроля нормативных требований.

  • Снижение трудоемкости подготовки отчетности.

Ограничения системы

  • Система предназначена для использования сотрудниками одного авиапредприятия.

  • Доступ функциональным возможностям системы определяется назначенными пользователям ролями и разрешениями.

  • Пользователи могут работать только с проектами, к котором им предоставлен доступ.

  • Создание нового проекта допускается только после согласования соответствующего устава проекта.

  • Интеграции с внешними информационными системами не предусмотрены.
