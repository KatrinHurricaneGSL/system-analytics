AVPM : GET /api/projects/{projectId}/member-options

Created by Перейти, last modified on нояб. 14, 2026

Возвращает список пользователей для назначения сотрудниками проекта.

Доступ: право project:access и роль manager в проекте.

Используется в UC-4. Изменение состава сотрудников проекта.

Схема работы

Алгоритм

  1. Проверить право project:access и найти проект по идентификатору. Если проект не найден, вернуть 404.

  2. Проверить наличие записи в project_members с ролью manager для текущего пользователя. Если роль отсутствует, вернуть 403.

  3. Получить все учетные записи из accounts и отсортировать их по имени, затем по username.

  4. Вернуть массив пользователей для выбора в форме. Сервер не исключает действующих менеджеров и сотрудников проекта, интерфейс самостоятельно исключает менеджеров из списка выбора.

Входные параметры

Параметр пути (PATH). Тело запроса и QUERY-параметры отсутствуют.

Поле

Тип

Обязательно

Описание

projectId

integer

Да

Идентификатор проекта

Ответ

200 OK: возвращает массив объектов ProjectUserOptionDto.

Поля каждого элемента массива:

Поле

Тип

Описание

id

integer

Идентификатор пользователя

username

string

Логин пользователя

name

string

Имя пользователя

email

string

Электронная почта

Если учетные записи отсутствуют, система возвращает 200 OK с пустым массивом [].

Список формируется без фильтрации по организации и правам пользователей на другие проекты. Поиск и серверная пагинация отсутствуют.

Право project:create не заменяет роль manager и не дает доступа к этому методу без назначения менеджером проекта.
