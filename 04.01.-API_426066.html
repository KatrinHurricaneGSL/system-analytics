AVPM : 04.01. API

Created by Перейти, last modified on нояб. 14, 2026

Раздел содержит описание методов API для создания, изменения, согласования и просмотра уставов проектов.

Каждый метод описан на отдельной странице, которая содержит назначение, схему работы, алгоритм, входные параметры и ответы.

Дополнительная документация: сценарии использования и модель данных.

Общие правила

Все методы требуют авторизации через заголовок Authorization: Bearer {token}.

Для запросов с телом используется Content-Type: application/json.

Необходимые права доступа указаны на страницах методов.

Поля JSON используют формат camelCase, даты передаются строками даты и времени, суммы имеют тип number. Необязательные поля ответа со значением null могут отсутствовать.

Примеры запросов содержат условные идентификаторы. Для выполнения запросов необходимо использовать идентификаторы существующих записей.
