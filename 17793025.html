AVPM : GET /api/project-charters

Created by Перейти, last modified on нояб. 14, 2026

Возвращает реестр уставов с возможностью поиска, фильтрации и постраничной загрузки.

Доступ: право project_charter:access.

Используется в UC-1. Просмотр реестра и карточки.

Схема работы

Алгоритм

  1. Проверить право доступа к реестру уставов.

  2. Применить фильтры по проекту, статусу и ответственному. Выполнить поиск без учета регистра по названию и цели устава, названию проекта и организации.

  3. Отсортировать уставы по дате последнего изменения, а при ее отсутствии по дате создания, от новых к старым.

  4. Вернуть запрошенную страницу реестра. При выборке не учитывать членство пользователя в проекте.

Входные параметры

Параметры запроса (QUERY). Все параметры необязательны. Тело запроса отсутствует.

integer

Идентификатор связанного проекта

status

string

Статус устава: draft, submitted, approved, rejected

responsibleUserId

integer

Идентификатор ответственного

page

integer

Номер страницы. По умолчанию 1, значения <= 0 заменяются на 1

pageSize

integer

Количество записей на странице. По умолчанию 20, значения <= 0 заменяются на 20, максимум 200

Ответ

200 OK: возвращает массив уставов без общего количества записей.

Если по заданным фильтрам уставы не найдены, система возвращает 200 OK с пустым массивом [].

Неизвестное значение status не вызывает ошибку и используется при поиске совпадающих записей.

Ошибки

Код

Причина

401

Пользователь не авторизован

403

У пользователя отсутствует право project_charter:access

Другие ошибки проверки параметров описаны в общей документации API.

Пример запроса

GET /api/project-charters?status=approved&page=1&pageSize=20
