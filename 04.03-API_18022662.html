Общие правила

Все методы требуют Authorization: Bearer {token}. Запросы с телом используют JSON и Content-Type: application/json.

Права доступа зависят от метода. Операции с задачами проверяют соответствующие разрешения kanban:*. Для большинства операций с досками достаточно JWT, а удаление доски и управление участниками требуют прав владельца.

Поля JSON используют camelCase. Поля со значением null могут отсутствовать. Даты передаются строками, числовые значения часов и денежных сумм имеют тип number.

Для пустого описания задачи используется "", для пустых массивов []. Атрибут [Required] для int и bool не отличает отсутствие значения от 0 и false.
