AVPM : POST /api/boards/{boardId}/members

Created by Екатерина Попова on нояб. 15, 2026

Добавляет пользователя в участники доски.

Доступ: JWT. Добавление участников разрешено только владельцу доски.

Схема работы

Алгоритм

  1. Проверить JWT и найти доску по идентификатору boardId.

  2. Сравнить владельца доски с текущим пользователем. Если идентификаторы не совпадают, отказать в добавлении участника.

  3. Проверить существование пользователя по userId.

  4. Создать связь между доской и пользователем в таблице board_users.

  5. Сохранить изменения и вернуть 204 без тела ответа.

Входные параметры

Параметр пути (PATH) и тело запроса (BODY, JSON).

Где

Поле

Тип

Обязательно

Описание и ограничения

PATH

boardId

integer

Да

Идентификатор доски

BODY

userId

integer

Да

Идентификатор добавляемого пользователя. Отдельная проверка значения > 0 отсутствует

Ответ

204 No Content: пользователь успешно добавлен в участники доски, тело ответа отсутствует.

Ошибки

Следующие ситуации вызывают исключения, которые метод не преобразует в отдельные HTTP-ответы:

  • Доска не найдена.

  • Текущий пользователь не является владельцем доски.

  • Добавляемый пользователь не найден.

  • Пользователь уже состоит в участниках доски и повторное создание связи приводит к ошибке.

Контроллер не гарантирует возврат 403 или 404 для перечисленных ситуаций.

Пример запроса

POST /api/boards/101/members
Content-Type: application/json

{
  "userId": 10
}

При успешном добавлении сервер возвращает 204 No Content без JSON.
