AVPM : POST /api/project-charters/{id}/reject

Created by Перейти, last modified on нояб. 14, 2026

Отклоняет текущий шаг согласования и присваивает уставу статус rejected с указанием причины.

Доступ: право project_charter:approve и назначение пользователя согласующим на текущий шаг.

Используется в UC-6. Отклонение устава.

Схема работы

Алгоритм

  1. Проверить, что причина отклонения не пустая и не состоит только из пробелов. Удалить пробелы в начале и конце текста.

  2. Найти устав по идентификатору. Проверить статус submitted и наличие активного шага со статусом in_progress.

  3. Проверить, что approverUserId активного шага совпадает с идентификатором текущего пользователя.

  4. Присвоить текущему шагу и уставу статус rejected. Сохранить причину отклонения, идентификатор согласующего и дату решения.

  5. Увеличить версию устава, сохранить его состояние в истории версий и добавить в журнал событие step_rejected.

  6. Вернуть обновленную карточку устава. Предыдущие решения сохраняются, следующий шаг согласования не запускается.

Входные параметры

Параметр пути (PATH) и тело запроса (BODY, JSON).

Где

Поле

Тип

Обязательно

Описание

PATH

id

integer

Да

Идентификатор устава

BODY

reason

string

Да

Непустая причина отклонения. Пробелы в начале и конце удаляются

Ответ

200 OK: возвращает обновленную карточку устава со статусом rejected.

Структура ответа совпадает с GET /api/project-charters/{id}.

Ошибки

Код

Причина

400

Отсутствует причина отклонения, устав имеет неподходящий статус, нет активного шага или пользователь не назначен согласующим. Ответ содержит {message}

404

Устав не найден

401

Пользователь не авторизован

403

У пользователя отсутствует право project_charter:approve

При перечисленных ошибках данные устава остаются без изменений. Повторная отправка запроса после успешного отклонения возвращает 400, поскольку устав больше не находится на согласовании.

Пример запроса

POST /api/project-charters/101/reject
Content-Type: application/json

{
  "reason": "Уточнить бюджет испытаний"
}
